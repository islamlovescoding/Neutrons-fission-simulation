# ☢️ Neutron Fission Simulation

A 2D nuclear chain reaction simulation built with Python and pygame.
Neutrons fly around, hit uranium atoms, split them, and spawn new neutrons.
it's also my first project !

## what it does

- neutrons bounce around the screen and split uranium atoms
- each collision spawns 2 new neutrons and a flash effect
- live dashboard shows neutron count, atom count, and game mode (nuclear reactor mode/ gas mode)

## controls

 `F` change modes
 `R`  restart the simulation with random positions

## how to run it

1. install pygame
   pip install pygame
2. add your own sound files to a /sounds folder (or delete the music lines)
3. run it
